# SAVORÉ — Universal Restaurant Sales Demo

Premium fictional restaurant/café frontend for Novariyan sales demos.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Customize for a client
Replace the fictional SAVORÉ data, imagery, contact details and colors in `src/main.jsx` and `src/styles.css`.

The demo intentionally has no backend, authentication, payments, admin dashboard, or restaurant-management functionality.
